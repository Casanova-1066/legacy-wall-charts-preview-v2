# Competition Catalogue

The source of truth for the initial competition catalogue is `data/competition-catalogue.json`.

The TypeScript application export is `src/data/competitionProfiles.ts`.

The catalogue contains 83 profiles from the supplied reference guide covering football, rugby union, rugby league, tennis and cricket. Source descriptions are preserved. `layoutEngine` is an inferred planning field and must be versioned by season before publishing official or paid historical charts.
